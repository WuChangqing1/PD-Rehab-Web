# 注册与舒缓训练验收说明

## 使用

Web登录页点“手机号注册”，填写本人大陆手机号并同意保存本人的训练档案，再获取验证码并注册。首次成功请保存恢复码。注册只供App账号使用，没有增加Web患者功能页或工作人员权限。验证码和恢复码不写入浏览器持久存储；已有号码不会重复创建患者。工作人员使用原账号登录。

Web“康复训练 → 钢琴节奏训练”默认舒缓40BPM；高级设置可选标准60BPM或自定义，自动调整难度默认关闭。左右手练习看蓝色左手、橙色右手及相应字母/触屏键，双手提示同时按两键。曲目跟弹的新初级也为40BPM，历史会话按原参数执行。

App设置的“舒缓节奏”默认开启，可关闭恢复标准。重新安装独立QA包后需在该包里登录，不能读取正式包的私有本机记录。课程仍为3门10段，中英文界面均能选择全部课程。

## 记录比较与限制

实际有效提示提前量受上一提示结束窗口约束，保存归一后的实际参数。例如默认40BPM/1200ms保持，60BPM请求1200ms会归一为849ms；无法显示的过密组合会提示调整。原标准缺省700ms保留；旧激进自定义串行窗口行为不在本轮扩大修改范围。

App本地舒缓/标准按版本与有效参数单独比较；Web原生钢琴趋势包含实际提前量。App上传记录仍通过“软件端记录”查看，尚未合并进Web原生钢琴趋势/日历。反应时保持原始时钟定义，不能将提前提示后的数值直接与历史标准比较为康复改善。

发布只作用PD仓库、PD后端及其静态目录；不改Nginx、端口、模型/AI/短信密钥，不执行数据库迁移。代码切换前后核对数据库摘要和迁移版本，其他7项服务PID必须保持。失败时先停止PD，再退回旧代码及入口HTML、恢复被覆盖的静态文件后启动；不恢复/回滚业务数据库。精确发布SHA与线上结果将在部署记录补齐。
