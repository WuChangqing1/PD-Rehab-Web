## 本轮：Web注册与患者反馈优化（发布结果另见验收记录）

### Web手机号注册

按用户明确选择只做注册，不建设患者门户。工作人员登录页新增入口 `/register/phone`，复用同一短信提供方及已有移动账号接口。成功显示账户和一次性恢复码；已注册号码不重复建档。PATIENT Token不写入工作人员会话，临时移动会话后台注销，错误验证码不会清掉原工作人员登录。验证码、恢复码和Token只保留内存，不写localStorage或公开日志。注册后在App使用该手机号；Web工作人员权限不改变。

### Web入门节奏和手别

原默认60BPM为每秒1拍；新舒缓起步40BPM为每拍1.5秒。提示期望提前量由700ms增至1200ms，标准/自定义保留，自动调整默认关闭。实际可提前量按真实cue间隔与判定/保持窗口约束：40/1200可完整实现，60/1200实际归一为849ms，过密且无法正确显示的组合在开始前提示调整。保存的是实际有效参数，runner展示和记录一致。

曲目跟弹新初级由60BPM改40BPM，半拍由500ms改750ms；旧已保存60BPM会话按原参数回放、续训和算分，不被新默认改写。明确左右手的cue使用左蓝、右橙，并显示手侧和真实字母/触屏键；双手同时和交替不混淆。认知/无手侧cue不虚构手别。

### App舒缓设置

“设置→舒缓节奏”默认开启，关闭即标准。保留已有模式及手动难度，舒缓和标准分别保存等级。关键参数如下：

| 项目 | 原标准 | 新舒缓 |
|---|---|---|
| 正确完成后到下一题 | 700ms | 1500ms |
| G1/S1演示音符起点间隔 | 900ms | 1500ms |
| 演示结束过渡 | 600ms | 1000ms |
| G3规则提示 | 1500ms | 2500ms |
| G2/G3/M2响应窗口 | 依模式/等级约2–4秒 | 至少5000ms |
| 节奏档位 | 40/45/50/55BPM | 30/35/40/45BPM |
| 连续优秀后自动升速 | 原标准规则 | 不自动升级 |
| 400ms按住要求、原始时钟与评分公式 | 保持 | 保持 |

G2/G3会在正确按满400ms后提前结束，所以名义窗口很长仍会显得赶；加长题间过渡直接针对这一原因。M1/M2有真正左右手/双区定义，使用一致蓝/橙、文字及实际触点对应；没有手别定义的认知练习仍按键位/规则提示，不能随意给它伪造左右手评分。
