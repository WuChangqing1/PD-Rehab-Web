# Web 医院反馈实现计划

> For agentic workers: Use superpowers:executing-plans to implement task by task.

Goal: 完成用户两轮审核确认的医护录入、录音和训练后 AI 点评，不更改训练规则或 App。
Architecture: 复用现有患者和问答 API。备注保留 doctor_notes 存储名以兼容旧数据；训练点评由服务端鉴权后提取白名单数据。录音只在浏览器本地处理，不接入转写模型。
Tech Stack: Vue 3, TypeScript, FastAPI, SQLAlchemy, pytest, Node test, Playwright。
Spec: 本聊天 2026-11-23 用户两轮审核及“确认，都确认，开始修改优化”。

## 边界

不接入视频、不更改琴键/速度/训练规则、不接入新模型、不自动推送部署。
不自动迁移旧病史、不把年龄换算成生日、不把开关期等同于是否用药。
本轮新增临床字段的界面方案保存在说明文档；不把尚未接入的字段显示为已保存。
点评只携带项目、手别、速度难度、完成情况及白名单指标，不携带身份、病历、影像、自由备注或原始按键。

## 验收重点

护士可保存备注，但不能管理账号或删除患者。
保存失败、取消、中断、初始化加载旧结果不弹出点评；同记录不重复弹。
录音授权晚返回、页面退出、取消和重录均释放麦克风，不自动上传录音。
点评服务端校验患者授权、记录完成状态及明确同意，不信任 URL 传来的指标。
问答发送失败保留重试内容；患者切换、账号切换不能沿用错误记录。

- [x] 4. 训练保存成功后触发通用弹窗，点击进入 AI 问答并自动发送，失败重试；不动训练算法。

Ruling: 点评并发单飞按现有单 worker 后端验收，不承诺跨进程幂等。
