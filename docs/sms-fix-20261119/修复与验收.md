# 短信验证码获取500修复

日期：2026-11-19；基线Web3b4bb90。

## 根因

生产异常为SQLAlchemy StaleDataError：mobile_auth_limits更新预期1行但实际0行。请求在_new_challenge提交时报错，尚未进入短信供应商发码。SessionLocal关闭autoflush；已有过期窗口在内存续期后，清理DELETE仍按数据库旧过期时间将它删除，随后commit刷新UPDATE导致500。多日未再次发码且所有限流记录已经存在时可稳定触发。

## 修复

只在_new_challenge添加一次db.flush()及注释，先持久化本事务内的限流续期与挑战，再执行既有保留期清理。事务仍在供应商调用前提交；发送失败继续消耗限流预算，冷却/日限额/IP限额/全局预算及微信流程不变。没有重置生产限额、删除业务数据、更换密钥、修改数据库结构或改动Web/App界面。

## 验证

短信相关21项通过。完整后端623通过、2项既有跳过，退出0；独立只读审查无确认问题。未修改前端，不重建/覆盖静态页面；本次不要求用户重装App。
