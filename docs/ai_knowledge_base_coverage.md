# AI 知识库覆盖与引用验证

批准集合为 15 份文档，覆盖账号、Web/App 操作、钢琴/舞蹈、指标、计划与进度、同步、面部分析、随访导出、AI 本身和故障处理。其余扫描资料记录在清单，未审核内容不冒充已收录。增补指南依据当前功能；技术历史说明标注版本差异，不作为临床结论。

## 检索实现

采用现有架构内的中英文关键词与中文双字词法检索，按章节分段、约900字符步进/1100字符窗口、内容哈希去重，最多取6个普通证据片段和2个特定操作意图段落。不是向量检索，不声称完成语义检索或医学准确率评测。特定意图也从当前已授权文档提取正文，不能绕过撤销规则，也不使用旧的固定答案兜底。

检索前按数据库确认的调用者角色过滤，版本、来源、内容哈希保留。历史参考降低排序权重并提示版本限制。问题作为独立用户消息，资料作为有界系统证据；不把所有文档一次塞入 Prompt。复用原 GLM 服务、模型配置和问答表；未修改注册登录协议、患者映射或同步核心。

来源由检索结果生成稳定本站 ID 和可用章节锚点；模型不能自己造链接。API 返回规范 HTTPS 地址供 App；Web 按当前 base 转成同站路由，根路径和子路径都测试。缺少资料时说明不足；无供应商且未匹配时仍明确503。药物调整和诊断等不凭训练值回答。

普通用户无法检索工作人员/管理员资料，更不能读取其他患者数据或系统密钥；患者个人结果仍走原授权 API。现有问题、回答、模型和时间保存在 expert_chat_turns，导出遵守原所有者权限。没有声称新增患者病历问答。
