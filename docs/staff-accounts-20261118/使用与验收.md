# 医护账号与患者姓名更新

## 使用方法

Web登录页点击“医护注册”，填写登录账号、密码、姓名、联系电话及申请医生/护士身份。提交后等待管理员审核，待审核及拒绝的申请不能登录，也不能访问患者。患者手机号注册入口保留，注册患者不获得医护权限。

管理员登录后从侧栏或账户菜单打开“医护管理”，审核申请、选择医生或护士身份，查看待审核/已通过/已拒绝申请，并启用、停用或调整医护身份。至少保留一个活跃管理员。身份及停用立即对旧登录凭证生效；自己降级后自动退出管理页，不保留管理员菜单。

当前为单机构共享工作区：医生和护士共享患者查看与基础资料录入；护士可采集评估、执行训练及清理自己未完成的任务，不可修改医生专业意见、提交他人训练计划快照或删除已完成记录；管理员才可管理账户和删除完整记录。患者仅本人访问不变。保留既有明确撤销的患者授权。现有Web没有独立训练计划编辑/批量导出页面，本轮不虚构新增这些页面；服务器权限对相关现有接口执行。

App升级本轮0.1.73后，“我的账号 → 修改姓名”，服务器确认且安全会话保存成功后才显示成功。首页、账号、训练页显示同一患者姓名，内部登录账号与患者ID不变，原记录不会重新归属。医生/护士在Web编辑患者姓名后，App联网连接或同步时刷新。发生并发修改时，先展示最新姓名，再由用户明确确认是否覆盖；离线失败保留输入，不假报保存完成。
