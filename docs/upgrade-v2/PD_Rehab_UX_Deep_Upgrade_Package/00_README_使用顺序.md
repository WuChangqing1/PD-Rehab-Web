## 推荐流程

1. 将本 ZIP 解压到 `D:\CodingData\Competition\PD\PD-Rehab-Web\docs\upgrade-v2\`，也可以放在当前实际项目目录的 `docs/upgrade-v2/`。
2. 将 `HARNESS_执行总Prompt.txt` 原文发送 DeepSeek Harness，并指定代码工作区为当前仓库。
3. Harness 首先审计 Git 工作区、线上站点、ZIP 对应源码及服务器，按文档列出实际可完成/待模型/待素材事项。
4. 依次开发：信息架构与设计系统 → 芭蕾媒体链路/视频 → 钢琴深度 → 微表情模型 Adapter → 数据闭环/性能 → 真机验收/部署。
5. 每阶段独立测试、截图、commit。禁止把未验证功能用 UI 或伪造结果包装为已经完成。

- PPT 是**技术参考材料**，不是实际 `FG-LGL`、`AUG-GCN` checkpoint、推理脚本或模型许可证的替代品。

- 对患者保留简洁、任务内嵌的安全退出/不适停止提示；无需把长篇研发免责声明放在主页面。
