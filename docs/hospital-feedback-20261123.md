# 医院反馈 Web 优化与验收说明

日期：2026-11-23。依据用户两轮审核确认，只修改 Web 医护填写流程、本地语音录音及训练结束后的 AI 点评。未修改 App、训练规则、视频内容或模型。

## 医护档案

共用操作中的医生备注改为备注，医护均可维护；保留 doctor_notes 存储名，兼容旧数据。护士仍不能删除患者或管理账号，原患者级授权及并发更新版本校验保留。

档案分为基本信息、帕金森相关信息、用药信息和可展开的补充病史。补充联系方式收起，日期可直接输入。首诊日期名称明确；开关期状态与是否正在用药不混同。帕金森相关用药支持多项标签录入，不预置未经临床确认的药物清单。常见合并症及康复经历点选只在明确编辑时更新旧文本，原自由描述保留。

实际医生、护士、管理员账号角色名称保持真实；诊断、处方等涉及医生职责的表述不机械替换。

## 本地语音界面

AI 康复问答提供语音输入、停止、取消、重新录制、本地回听以及麦克风权限错误提示。最多录制60秒，音频只留在当前浏览器内存，不上传。取消、重录、退出页面释放麦克风和对象 URL。

尚未接入语音转文字或方言识别，界面明确说明需用文字发送，不能声称已经识别成功。后续转写应先回填输入框，由用户确认后发送。

## 训练结束点评

钢琴、曲目跟弹及动作训练正常保存完成后，提供是否询问 AI 的弹窗。点击询问 AI 即明确同意发送有限数据，进入问答页自动发送；不再二次确认。取消、中断、保存失败、查看旧曲目历史均不触发。相同记录不重复弹出；快速双击不丢失待发送内容。取消弹窗不改变已保存结果。

服务端从数据库读取记录，检查患者权限、完成状态和明确同意。仅发送训练项目、手别或任务映射、速度难度、完成情况及白名单数值指标；保留输入来源，避免把自测当真人数据。不发送姓名、电话、患者或记录 UUID、自由备注、病历、原始事件、音视频或任意 JSON。

无可用指标时直接说明无法点评，不调用模型。回答要求区分训练表现与疗效，不作诊断、处方或个体训练剂量调整。普通问答仍不检索病历。接口复用已有 GLM 兼容供应商配置，本轮未更换模型。

失败时保留问题及训练关联，可以点击发送重试。关闭页面中止前端请求；账号切换清空未发送的点评上下文。持久化回答缓存结合单进程单飞锁，避免当前单 worker 后端的并发重试重复调用；多 worker 的跨进程幂等需另行实现。

## 新临床字段界面方案

本轮保持原数据库结构，不把未接入的新字段显示为已保存。后续起病侧与当前受累侧分别录入；是否正在服用帕金森相关药物与开关期状态分别录入。起病侧选项拟为左侧、右侧、不明确；用药情况拟为正在用药、未用药、未记录，最终选项需临床确认。

年龄直接录入、正式药物选项、进一步的康复经历问卷需明确存储与临床口径后接入。不从年龄推造生日，不回填推测病史，不删除旧值。视频待用户整理后接入；HIS、随访新模块和新识别模型暂缓。

## 验证与边界

前端完整测试393项通过；根路径和 /pd-rehab/ 构建通过。后端验收覆盖护士权限、患者授权、问答安全、训练点评及原有钢琴、动作和曲目训练接口。最新准确计数保存在本地 pytest.xml 验收报告。

真实 Chrome 已检查1440、820、390像素宽度的护士编辑保存、旧值保留和弹窗布局；本地 MediaRecorder 实录、回听、取消和退出释放；点评自动发送、快速双击、网络失败重试、同记录不重复弹出及刷新不自动发送。截图和日志在原项目 _deploy/hospital-feedback-20261123。前端393项通过，相关后端95项通过，两个 base 构建成功；另已实测英文麦克风拒绝提示和晚授权重录的单计时器及全部音轨释放。

浏览器点评使用隔离数据库和明确的供应商测试替身，未访问生产患者或调用线上 GLM，不把替身结果当作模型效果验证。现有依赖弃用及媒体 OpenAPI operation ID 重复警告单独记录，未改无关模块。

2026-11-23 后续已获用户明确授权推送并部署。本次发布不涉及生产数据库迁移；最终线上状态和回滚材料记录在服务器 releases/hospital-feedback-20261123 目录。
