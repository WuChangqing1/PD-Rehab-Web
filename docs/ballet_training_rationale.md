# 芭蕾动作训练：设计依据与参数出处

版本：v1.0.0
日期：2026-10-01

本文回答一个问题：**芭蕾模块里的每个数字和每条规则，是从哪来的。**
它同时也是「哪些东西我们不知道」的清单。

---

## 1. 设计依据来自哪里

依据来自本项目指导老师给出的方向（见任务书），要点是：芭蕾 / 舞蹈可以从
**平衡、姿态、重心转移、节奏提示、动作流畅性、全身协调**这些角度设计训练；
而**外部节奏、清晰口令、分解动作、慢速动作、音乐提示**是这类训练非常重要的交互方式。

这段方向决定了三件事，而不是一句宣传语：

1. 训练不能只是「上传视频 → 算角度」。它必须是**有节拍、有口令、被分解**的任务。
   → `BalletRhythmPanel`、`ballet/rhythm.ts` 的口令序列与节拍调度。
2. 动作要覆盖**手臂、姿态、腿部、重心**四类，而不是五个肩部动作。
   → 五个 `BALLET_*` 动作。
3. 同一动作在**坐姿与站姿**下是不同的任务，必须分开记录。
   → `execution_mode`。

---

## 2. 五个动作的选择理由

| 动作 | 对应方向 | 为什么选它 |
| --- | --- | --- |
| Port de Bras | 手臂活动范围、流畅性、对称 | 芭蕾最基本的臂线，坐姿也能做，慢速可控 |
| First Position Hold | 姿态、平衡、保持 | 静态保持，直接对应稳定性与躯干直立 |
| Tendu | 重心转移、腿部活动范围 | 单腿伸展 + 重心留在支撑腿，是重心转移的入门形 |
| Demi-Plié | 膝髋屈曲、对称、控制 | 双侧对称的下肢动作，速度慢，便于观察左右差异 |
| Weight Shift | 重心转移、全身协调 | 把重心转移与手臂动作组合，接近功能性活动 |

选择标准是**能否被单目摄像头客观测量**，而不是动作好不好看。
因此没有选需要跳跃、旋转、单脚尖支撑的动作：那些在现有测量条件下要么拍不到，
要么会把「镜头没拍到」误报成「患者做不到」。

## 3. 每个数字的出处

| 参数 | 取值 | 出处 / 性质 |
| --- | --- | --- |
| 默认 BPM | 60（Demi-Plié 50） | **起始默认值**，医生可改。选 60 是因为口令按 4 拍一组读出来大约 4 秒，
对帕金森患者是可跟上的慢速；**这不是处方，也没有研究给出这个数字** |
| 保持拍数 | Port de Bras 4 拍、First Position 8 拍 | 起始默认值，使一次完整重复落在 12–16 拍内 |
| 目标次数 | 3–5 次 | 起始默认值。原瑜伽动作的次数（5–8 次）沿用了一部分 |
| 口令分句长度 | 每句 2–4 拍 | 依据「分解动作 + 清晰口令」；4 拍是一小节，最容易数 |
| 伴奏和弦进行 | C–Am–F–G，每拍一个音 | 纯合成、可循环、无版权。**不声称有音乐治疗效果** |
| 门限（时长 ≥2s、有效帧 ≥0.5、可见度 ≥0.5、幅度 ≥10°） | 未改动 | 沿用原有 Pose 质量控制门限，本轮未调整 |
| 坐姿 / 站姿支持表 | 见 `exercises.py` | 由动作的生物力学决定：Demi-Plié 需要负重，因此不提供坐姿版本 |

**所有 BPM、次数、保持时长都是训练设置，不是临床处方。** 它们的作用是给医生一个
起点，且每一项都可以在「高级设置（医生）」里改。

## 4. 我们不知道的事（必须写在代码旁边）

1. **芭蕾训练对帕金森患者的疗效，本系统不作任何声称。**
   界面上没有「改善 X%」「延缓衰退」这类表述，报告也不输出综合评分或严重程度变化。
2. **本模块没有做对照试验，也没有引用具体研究来支撑 BPM 或次数。**
   上表已逐项标注哪些是「起始默认值」。
3. **角度是单目估计。** 腿伸向或远离镜头时读数会偏小；`trunk_rotation` 是深度代理量。
   这两点由 `analyzer.py` 在结果里以 warning 形式如实说明。
4. **展示分（完成度 / ROM / 对称性 / 稳定性）没有公式**，因此恒为空。
   本模块只输出可复算的原始指标。
5. **`execution_mode` 为 `UNKNOWN` 的历史行**无法判断是坐姿还是站姿完成的。
   这些行不参与任何按方式分组的比较。

## 5. 与钢琴模块的边界

节奏提示在两个模块里含义不同，不能互相套用：

- **钢琴**：节拍是任务本身，患者要在拍点上按键，因此有 `timing_error_ms`。
- **芭蕾**：节拍是**外部时间参照**，帮患者把动作放慢、放匀；系统不判断患者是否「踩点」，
  只记录动作本身的幅度、速度、保持与稳定性。
