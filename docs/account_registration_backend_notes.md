## 必要的安全补强

- 注册统一小写，并以不区分大小写的查询拦截已有工作人员账号名；注册患者编号使用原数据库号段分配，账号、患者、映射和首会话同一事务。
- 仅 PATIENT 可使用移动认证接口；工作人员登录拒绝 PATIENT。患者的每个受保护请求先核对可撤销会话，再按精确方法/路径白名单和患者 UUID 授权。bootstrap 对患者只返回本人，不返回工作人员目录。
- 访问凭证15分钟、刷新会话30天，刷新凭证仅保存哈希，旋转使用数据库 CAS。SQLite 的认证读写事务用 BEGIN IMMEDIATE 串行，防止多进程注册/刷新/改密竞态。
- 会话保留上一刷新凭证哈希，仅用于退出补偿，不能用旧凭证刷新。退出与一次轮换相遇时仍能撤销该设备。
- 移动 Token 不能在数据库角色变化后变成工作人员 Token。
- 在任务允许范围之外，只额外修改 `face_recordings.py`：既有播放器使用独立 Cookie 而非 Bearer，故需把移动会话 ID 写入短期播放凭据，并在每次播放/下载核对撤销状态。这是防止退出后仍能访问录像的必要兼容修复；不改视频算法或保留规则。
- 新增真实迁移测试文件，验证带原工作人员、患者和训练记录的旧数据库升级及安全回滚。
