# 随访日历、训练趋势与芭蕾封面交付记录

## 使用方式

在患者选择器搜索 `FOLLOWUP-20261017`，选择「随访演示」，进入「随访与报告」。该独立患者默认显示「示例记录」，有清晰的演示数据标识。实际患者仍默认显示实际记录，示例不会进入其趋势结论。

- 日历按北京时间、记录开始日期归档；有训练、评估和未完成标记，可切换月份。点击日期列出当天所有模块的记录，查看结果不会启动训练。
- 趋势按钢琴练习、芭蕾动作、曲目跟弹、左右手敲击分类。不同练习、难度参数、双段曲目速度和算法版本分别比较。
- 报告显示最近值、前次值、变化、中位数、范围和可比次数。比例差使用「百分点」。缺失值不补零，不生成临床改善结论。
- 康复训练主页使用正在跳芭蕾的人像封面，保留五种动作各自的示范内容。
- 清理重复页面副标题、生成过程描述和无关说明，保留必要的操作、安全、来源与错误提示。

## 独立示例数据

用户明确选择「为独立演示患者添加示例数据」。患者保留编号为 `DEMO-FOLLOWUP-20261017`，不包含真人身份、疾病判断或面部预测。

| 类型 | 数量 | 来源与计算 |
|---|---:|---|
| 钢琴 | 112 轮，14 个练习变体各 8 轮 | 合成按键事件，调用现有 compute_metrics；原始事件保留 |
| 芭蕾 | 40 轮，5 个动作各 8 轮 | 合成角度序列，调用现有 analyse_series；不编造 0–100 分 |
| 手指评估 | 8 次评估、16 个左右手结果 | 合成开合信号，调用现有 extract_features；保留信号文件 |
| 曲目跟弹 | 每个现有活跃工作人员 8 轮 | 合成 CUE/DOWN/UP 事件，调用现有 analyze_events；沿用归属权限 |

固定 UUID、保留编号和数据集标记共同防止覆盖其他患者。重复运行不重复写入；已有同编号但不匹配的患者会阻止写入。数据版本明确采用 example/synthetic 标识。摄像头帧质量、手别置信度没有真实采集依据，因此保持缺失；不编造面部分析结果。

## 指标与算法范围

未更改既有临床或训练算法。新增的是历史记录的日历归档、来源过滤、配置分组和客观统计层。

- 钢琴：准确率、漏击率、反应延迟、节拍误差、波动、完成率；各配方增加保持节奏、同步、变速分段、按放时长、错位、逆序和选择性反应的已存指标。强拍识别不显示按压力度。
- 芭蕾：次数、保持时间、速度、有效采样比例、左右角度差、躯干角度与波动，以及动作相关关节角度；姿态保持只展示有意义的保持和稳定指标。
- 曲目：首次及全部按键准确率、反应延迟、跳过、误按、完成率。
- 手指：左右手频率、幅度、速度、周期、变异、斜率和中断等；没有采集的质量指标显示暂无数据。
