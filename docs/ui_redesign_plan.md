# UI 视觉升级与训练启动重构

## 已核实的现状
- 工作区在开始时干净，无项目 AGENTS.md。沿用 Vue 3、Element Plus、Pinia 和现有训练引擎。
- TrainingHubPage 的 PatientSelector/v-else 隐藏完整训练目录；PianoTrainingPage、MovementTrainingPage 也以前置选择器阻断浏览。
- PianoTrainingPage.begin 在创建会话前设置 started/taskMode；普通训练预备 2 秒，基础测试 3 秒。
- patientContext 缓存不会在启动时验证删除状态；钢琴基线只在挂载时加载，可能混用患者数据。
- MovementTrainingPage 纵向依次堆叠方式、长卡片、示范、开始、录像、结果，选择动作需要大量滚动。
- 全站卡片相邻 margin 与 grid gap 叠加，工作台同排卡片顶部错位；默认组件、浅灰文字、缺少视觉主次使界面单调。

## 设计与实施
1. 先浏览训练目录和配置，开始时复用患者选择器；URL 指定与明确选择的患者可复用，最近使用不自动选中。
2. 统一启动检查与全屏 3/2/1：实时验证身份、准备音频/会话、倒计时、进入患者任务。取消、卸载与过期异步响应不启动；不创建无患者记录。
3. 保留原算法、配方、基础测试、自适应与素材审核规则。无基线时测试先行，保留所选练习并在测试后恢复。
4. 建立冷灰底、白色内容、蓝色交互、青色辅助的统一系统；增加结构化封面、页眉与分区编号，统一表格、表单、状态与触摸尺寸。
5. 训练中心两张等高主卡；钢琴选择与预览分栏；芭蕾紧凑动作列表与示范分栏，录像只在任务模式出现。
6. 工作台增加快捷入口与统一统计卡；评估先浏览再选人；患者档案、详情与随访继承全局系统并针对布局调整。
