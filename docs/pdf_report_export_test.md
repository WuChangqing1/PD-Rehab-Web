# 随访 PDF 日期与内容验证

功能：[使用说明](pdf_report_export_guide.md)。所有后端测试均包括在本轮 706 项 pytest 中，相关前端测试包括在 397 项测试中。

日期为UTC+8，包含首尾日；支持单日、跨月、跨年、最近7/30天、本月和全选历史。仅起或止日期不再被误标成全部历史，后端明确拒绝不完整范围。没有患者时不下载全机构资料；服务端重新验证患者授权。

PDF A4竖版，嵌入中文TrueType字体，多页重复表头、矢量趋势和页码。用空数据、300条记录、长字段、不同任务/版本/参数、完成面部结果和真实零值验证；不混合来源造统一康复分。App保持原字段与任务口径，只展示保存的结构化结果。

报告只作PDF投影：递归去掉嵌套原始按键事件，不修改业务存储或JSON/CSV；不为报告读取/重新哈希大视频。审查发现的这两个问题已失败复现并修复。响应no-store，在内存生成，无长期公开临时PDF。

本机浏览器真实下载 `patient-QA-EXPORT-ONLY-all-history.pdf`，已渲染检查中文/表格与页码。手机开始、结束两个日历均约324px，390px屏幕内可选择；原646px双日历已替换。导出启动后锁定患者/日期/格式，切患者取消旧请求。

Google Fonts官方NotoSansSC开源字体经本地转为静态TrueType用于验收，许可证和SHA记录在产物证据，不把Windows商业字体复制到服务器或Git。生产需设置PD_REPORT_FONT并先验证；本轮未部署。
