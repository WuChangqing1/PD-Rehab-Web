# Web 实时语音输入：百炼配置与验收

## 范围与状态

Web 的 AI 康复问答使用阿里百炼 `fun-asr-realtime` 将语音转为输入框文字。原有 GLM 继续回答问题。无需在本地或服务器安装语音模型、CUDA 或 FFmpeg，新增直接依赖为 `websockets==17.1`。

本功能需要后端私密配置。未配置密钥时语音按钮不可用，文字问答仍可使用。协议测试替身只验证交互；真实普通话验收见文末。经用户授权，发布脚本见 `scripts/releases/asr-api-20261123/`，实际线上状态以发布验收证据为准。

## 开通与密钥

1. 在阿里云百炼控制台选择北京地域，确认可调用 `fun-asr-realtime`，检查额度和账户计费设置。
2. 创建专用 API Key，优先限定到本项目的业务空间。不要使用短信 AccessKey，也不要复用 GLM 密钥。
3. 从该地域控制台复制 WebSocket 地址；支持 `wss://业务空间ID.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`，以及官方兼容地址 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`。不要填写 HTTP 聊天地址。
4. 密钥只在自己终端的隐藏输入提示中粘贴，不发到聊天、截图、GitHub或前端环境变量。

## 本机安全配置入口

在 PowerShell 执行以下命令。路径为本轮实际交付分支所在目录。

```powershell
Set-Location 'D:\CodingData\Competition\PD\Codex-Delivery-20261119\PD-Rehab-Web'
& 'D:\App\Business\Coding\Python\Miniconda\envs\pd\python.exe' scripts/configure_asr.py
```

脚本先询问非敏感的 WebSocket 地址，再通过 `getpass` 隐藏输入 API Key。它用无音频任务检查授权和协议启动，随后断开无音频连接，成功后才原子替换 `backend/.asr.env`；失败不覆盖原配置。该文件已加入 `.gitignore`。此检查仍可能受供应商计费规则影响，不是识别准确率测试。

脚本在写入密钥前去除 Windows 文件继承权限，仅授予当前账户访问；Linux 文件权限为 `0600`。不要把配置文件放到共享盘。当前应用会读取这份配置；配置后重启本机后端即可。不要在终端执行 `Get-Content` 输出密钥文件。

本机运行环境仍按项目运行说明启动前后端；前后端必须同源，HTTPS 或 localhost 才能使用麦克风。

## 操作方法

1. 登录医护账号，进入 AI 康复问答。
2. 点击“语音输入”，允许麦克风权限；界面显示“正在识别”后开始说话。
3. 普通话、重庆话、四川话均先使用同一中文模型，不填写虚构的方言代码。
4. 文字实时显示。识别时暂时锁定文本编辑和发送，避免修订覆盖手工内容。
5. 再次点击停止，等待尾句确认，检查文字后再发送。Enter 发送，Shift+Enter 换行；中文输入法选字不会误发送。
6. “取消本次输入”会还原开始语音前的文字。切走页面、后台隐藏或退出会取消采集并释放麦克风。
7. 单次最多约60秒，超时自动停止。网络中断时保留已收到的文字，并允许继续手工编辑。

点击麦克风后，音频经本网站后端流式传给阿里百炼。本平台不将音频落盘，也不生成回听文件；云服务商的数据处理规则需按所开通服务确认。识别文本只有点击发送后才交给GLM。

## 上线配置流程

不需要数据库迁移。不修改已有 GLM、短信、患者、训练和模型配置。

1. 将新代码和双 base 前端构建作为独立版本发布。
2. 服务器专用配置路径建议 `/opt/pd-rehab/config/asr.env`。在服务器终端运行同一脚本并传 `--output /opt/pd-rehab/config/asr.env`，安全输入服务器使用的 Key。
3. 在 `pd-rehab-backend` 专用 systemd drop-in 添加 `Environment=ASR_CONFIG_FILE=/opt/pd-rehab/config/asr.env`。不要编辑其他项目服务。
4. 本实现票据和连接额度为单进程内存状态，必须继续使用当前单 worker；如果未来多 worker，先迁移到共享票据/限流存储。
5. 安装新增依赖，构建 `/` 和 `/pd-rehab/` 两种 base。
6. 审核项目 Nginx 两份模板新增的 `/api/asr/stream` 与 `/pd-rehab/api/asr/stream` 精确路径，保留 Host、协议、Upgrade，90秒超时。不要替换整个共享站点配置。
7. `nginx -t` 成功后才对 Nginx 执行受控 reload，只重启本项目后端；操作前保留原版本和配置回滚点。
8. 回滚时恢复原前后端、项目代理片段与专用 drop-in；密钥文件不进入备份包或 Git。

## 真实验收

用已同意测试的人员读同一组内容，每种口音分别验收，不能把模型宣称的方言覆盖当作本项目实测结果。

|测试|应检查的现象|
|---|---|
|普通话10句|实时出字、数字及标点、句末结果稳定|
|重庆话10句|同一内容逐句核对，记录漏字、错字和改正次数|
|四川话10句|与普通话同样方法核对，不混用结果|
|长停顿与轻声|停顿不会重复旧句；未识别时继续可键入|
|中文输入法|选字Enter不发送，完成输入后Enter发送|
|权限拒绝/迟到授权|明确报错，取消后迟到的麦克风也释放|
|网络断开/账号停用|终止云端流并释放麦克风，不继续计时采集|
|停止/取消/切页|最终文本只出现一次，取消还原，切页不留采集|
|PC/平板/手机|无横向溢出，按钮可点，输入文字可编辑|
|密钥保护|浏览器网络和构建资源没有供应商Key|

记录首次文字等待时间、结束确认等待时间、逐句错误及人工修改。帕金森患者的发声特点可能不同，应另做有同意的现场样本验证，不预先承诺准确率。不要采集或发送患者姓名、手机号等非必要信息。

## 连续输入收尾修正

真实HTTPS验收发现供应商任务完成与后端用户连接名额释放之间存在短暂时间差。前端收到最终文本后继续等待服务器关闭WebSocket，才恢复可再次输入的状态，避免立刻再次开始时误报BUSY。新增3项传输层回归测试；该静态补丁不重启后端、不改数据库或代理。
