# 2026-11-07 账号发布操作归档

这是本次在 fengz 上实际执行的 Python 脚本归档，不是可直接重跑的通用部署命令。它们限定帕琴律动目录、旧 SHA、迁移版本和唯一发布/备份目录；已经发布后再次执行会被前置检查拒绝。

- `prepare.py`：核对旧代码/工作区/校验清单，SQLite backup API 创建受保护副本，副本上迁移，逐表核对原行数与完整数据摘要、完整性和外键。
- `stage.py`：仅回环地址启动临时服务，使用副本数据库、独立存储、随机 JWT、禁用模型及 AI 外部调用，执行真实 API 测试，结束关闭其临时进程。

- `deploy.py`：核对包和预发布结果，只停止帕琴律动后端，备份并升级真实数据库，比较旧行摘要后启动；检查两个既有入口、原模型、匿名拒绝和其他六个项目服务状态/PID。前端无业务改动，不覆盖静态文件。

服务器受保护的发布目录中另有 `manifest.json`、Git bundle、源码包、迁移证据和日志；备份独立保存在 `/opt/pd-rehab/backups/mobile-accounts-20261107`。这些文件中可能包含内部部署信息或生产数据副本，未纳入 Git。

失败回滚分支保留新表和业务数据，停用旧版不理解的 PATIENT 并撤销移动会话，再切回已知旧代码；不会自动用旧数据库覆盖新写入。后续发布必须重新测量实际状态、选择新发布 ID 和适配脚本，不能盲目改几个常量执行。
